디지털 저지 컨트롤

연결 코드 (노트 10 ‘디지털 저지’·샤오미 ‘디지털 저지 램프’와 같은 4자리)

‘시작’ 후 노트 10(디지털 저지)과 샤오미(디지털 저지 램프)에서 같은 코드를 입력하세요. 코드는 기억되고, 이 페이지를 새로고침하면 노트 10도 자동으로 최신 버전으로 따라옵니다.

디지털 저지 명령

연결 전
이전 기록이 남아 있습니다 (발)

램프 폰 (샤오미)

연결 전 — 샤오미의 ‘디지털 저지 램프’에서 같은 코드를 입력하세요
램프 미세 조정 (사진 · 줌 · 이동)
램프 지정과 줌은 샤오미에서 먼저 하고, 여기서는 사진으로 확인·미세 조정합니다.
램프 폰 연결 후 표시
왼쪽 작은 사진 = 램프 주변 확대. ◀▲▼▶ 로 상자를 옮기고 ▢−/▢＋ 로 크기를 바꿉니다. 줌을 바꾸면 사진을 다시 받아 램프를 눌러 주세요.

현재 상황

선수 수: -
↑ 준비 모드에서만 오는 확인 사진입니다 (발시 카운트 중에는 사진·영상을 보내지 않고 번호·결과만 받습니다)

순별 발시·관중 기록

고치기 · 차례 · 기록 지우기
점수표의 칸을 누르면 관중 → 불 → 판정 전 순으로 바뀝니다.

이벤트

설정
카메라 설정

자동 줌 — 서 있는 선수 전원이 들어오게 맞추기

자동 맞추기
-
선수가 사대에 서면 슬레이브가 전체 화면에서 선수를 모두 찾아 잘림·키 크기를 검사하고, 전원이 들어오는 확대 영역(청록 점선)을 정합니다. ‘자동’이면 준비 모드에 들어갈 때(또는 준비 없이 바로 카운트를 시작할 때) 한 번 맞춥니다. 선수 위치가 바뀌면 다시 누르세요. 발시 카운트 중에는 바뀌지 않습니다.

카메라 · 수동 줌 · 사진

카메라
-
슬레이브 연결 후 표시
줌·카메라를 바꾼 뒤에는 ‘현재 상황’ 카드의 사진에서 선수가 모두 들어오는지 확인하고, 위의 ‘자동 줌’을 다시 하세요. 발시 카운트 중에는 줌·카메라 변경이 잠깁니다.
선수 설정
지정 없음 — 모든 선수 판정
선수 사진을 받는 중… 사진에서 선수를 직접 눌러 지정하세요. (사진이 없으면 위의 번호 버튼 사용)
번호는 사진 속 번호(왼쪽부터)입니다. 여러 명을 지정할 수 있습니다(예: 2·4·5번). 지정한 선수만 모니터링하고 점수표에 나옵니다. 발시 카운트 중에는 바꿀 수 없고, 다음 카운트부터 적용됩니다.
판정 설정
내 관 (뻐꾸기 소리)
관중 확인 최대 시간 (발시 후 초)
현소리 감도
녹화 화질
뻐꾸기와 램프(샤오미 폰)가 관중 신호입니다. 램프 폰이 연결돼 램프가 지정돼 있으면 뻐꾸기가 없는 관(1관·비봉정 등)도 램프로 관중·불을 판정합니다. 발시 후 ‘최대 시간’ 안에 내 관의 뻐꾸기가 울리면 관중, 아니면 불로 확정합니다 — 활이 약한 선수는 7초까지 걸립니다. 설정은 노트 10에 저장되고 연결될 때마다 다시 전달됩니다.
점검 도구

카메라 전체 비교 (ELP 줌 카메라 확인용)

브라우저가 열어 주는 카메라가 전부 나타납니다. 외장(USB) 카메라가 보이는지 확인하세요.

자세 인식 속도

기준: 중앙값 500 ms 이하 사용 가능, 300 ms 이하 여유.

소리 감지 확인 (노트 10 마이크)

-
현소리 후보·뻐꾸기(A/B/불명)가 들릴 때마다 한 줄씩 표시됩니다. 현장에서 A가 안 나오고 ‘불명’이 나오면 설정의 ‘뻐꾸기 판정’을 바꿔 보세요.
