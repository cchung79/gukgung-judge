# 관중 판정기 (시험판)

국궁 대회용 관중·불 자동 판정 시험 페이지. 발시음(마이크)과 과녁 램프 점멸(카메라)을 짝지어 시지 격자를 채웁니다.

- 페이지: index.html 하나로 동작 (설치 없음)
- 판정 기록·영상은 기기 안에만 남으며 이 저장소에는 올라오지 않습니다.

## single-shot (개인 시수 기록)

`single-shot/index.html` — 폰 한 대를 사대 뒤에 세워 두고 내 뒷모습의 발시(동작+현소리)를 세며, 과녁 램프 점멸이나 온달정 뻐꾸기(A형) 소리로 관중·불을 가려 1순 5발 시수표를 만듭니다. 기록은 기기 브라우저 안에만 저장됩니다.

### link/ — 두 폰 연결 시험 (마스터·슬레이브)
`link/index.html`: 아이폰(마스터, 심판대)과 노트 10(슬레이브, 사대 뒤)을 같은 Wi-Fi/핫스팟에서 WebRTC로 직접 연결해 보는 시험 페이지.
4자리 코드로 페어링(PeerJS 공개 시그널링, 라이브러리는 `link/peerjs.min.js` 동봉) → 연결 경로(LAN 직결/릴레이) 진단 → 지연(RTT)·시계 차 측정 → 마스터가 사진을 요청하면 슬레이브가 한 장 찍어 전송 → 모의 발시 이벤트 도착 지연 확인.
`link/` v0.4: 마스터에서 ‘자동 화면 맞추기’ — 슬레이브가 전체 화면에서 선수를 찾아 잘림·인원·키 크기를 검사하고, 모두 들어오는 소프트웨어 확대 영역(ROI)과 경고를 마스터로 보냄.

- link v0.9: 소리 감지(현소리·뻐꾸기)를 슬레이브 마이크(AudioWorklet)로 이동, 마스터는 마이크 없음. 마스터 새로고침 시 슬레이브 자동 갱신(버전 비교) + 강제 새로고침 버튼.
- link v0.10: 선수 0명이어도 새 사진 전송, 화면 맞추기 후 인원 자동 갱신 자동 시작(인원 변화·8초마다 사진 갱신), 제외 사유 수치 표시.
- link v0.11: 슬레이브 전원 모드(대기=카메라·마이크·인식 끔+검은 화면 / 활성=마스터 '발시 카운트 시작'), 배터리·신호 끊김 기록(화면 꺼짐 실험용).
- link v0.12: 발시 카운트 시작=인원 확정(잠금)·준비 상태에서는 인원 계속 갱신(2회 연속 확인)·화면 맞추기 과거 결과 흐림 표시.
- link v0.13: 카메라 재시작 직후 빈 프레임으로 사진 인코딩 실패(확정 오류) 수정 — 첫 프레임 대기 + 실패 시 상태 복구.
- link v0.14: 발시 카운트 중 사진·영상 전송 없음(번호·이벤트 메시지만), ‘발시 N번 선수’ 메시지, 슬레이브 전송량 집계 표시, 준비 중 확인 사진 on/off.
- **디지털 저지 v1.0** (`/digital-judge/` 노트 10 슬레이브, `/digital-judge-control/` 아이폰 컨트롤): link 테스트를 대체하는 최종 구조. 모든 판정(자세로 만작→발시 + 현소리, 뻐꾸기 A형 관중)을 슬레이브가 하고 컨트롤은 명령(준비·발시 카운트 시작/종료·대기)과 선수 수·순별 기록만 받음. 오늘은 줌 카메라 없이 뻐꾸기 소리만으로 관중 판정(램프 판정은 ELP 카메라 부착 후).
